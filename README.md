# Fork of ini-roundtrip

This is a fork of [ini_roundtrip] which is heavily based on [ini_core] with the
following changes:
- Add support for comments in none standard places
- Add helpers to simplify in place editing while preserving formatting.

Links to the original project:

[ [crates.io] ] [ [lib.rs] ] [ [docs.rs] ]

## MSRV

Current minimum supported Rust version is 1.85.0. This may be updated as
needed. MSRV bump is not considered a semver breaking change.
